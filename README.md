# Hyperdetection-Detection
This is a project I worked on for my end semester requirement at Karunya University. This project takes a dual nature approach by preprocessing a publicly available dataset of PPG-readings (after conversion to CSV) before then applying deep learning algorithms to a dataset of PPG readings to detect hypertension, specifically, MLP and 1D-CNN, to return a high accuracy rate of hypertension detection without being too hardware intensive, ensuring that this is capable of being run on most local PCs.

Download the dataset used for the project here:
https://www.kaggle.com/datasets/eliasjohnsabu/uci-bp-csv-format

Note: Ensure that you save the dataset, extract it and its subsequent files to the respective directories, and update those directories in the ML programs where applicable, when you run them on your device
